# Sci-fi action RPG — working profile

An offline single-player PC action RPG with controller support, a 3D isometric camera, stylized cyberpunk visuals, emotional narrative and repeatable combat missions. No title or story has been chosen.

The full game is classless: attributes, skills and equipment support guns, swords, traps, unarmed attacks and powers with synergies. Four equipped active abilities, tentatively including an ultimate. Strength, Dexterity, Constitution, Intelligence, Wisdom and Charisma affect combat and noncombat interactions. Builds cannot eventually unlock everything. Every character has a ground dash. Fast group encounters contrast with tactical bosses. Difficulty is changeable during play.

The long-term loop is hub → mission → procedurally assembled combat area → loot → hub → rewards, character development, base upgrades and companion conversations. Story decisions matter; optional repeatable missions remain available independently. Companions, base management, narrative, attribute effects, extensive loot and progression are outside the first POC.

## POC

- Small placeholder hub with a contract terminal.
- Gun, grenade and ground dash.
- WASD, right-click movement and controller input.
- Six connected procedural rooms and two drone enemy behaviors.
- Kill eight drones, extract, return and claim 100 credits. Repeat with another seed.
- Health, mission failure and retry.
- No character upgrade step.

Acceptance requires completing the full loop manually, checking movement/aiming/impact, and passing automated core and Unity tests. Backend C# experience; solo development, no budget, flexible schedule. Prioritize control responsiveness and impact before expanding scope.
