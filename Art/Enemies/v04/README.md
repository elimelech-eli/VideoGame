# Enemy v04 — reference-built mechanical models

Work started with **factory / regular ranged**, using its approved concept. This is an early static study, not an accepted production enemy or a replacement for the current game assets.

The first model has a camera sensor head, open mechanical torso/waist, individually built bearings/pistons, long narrow legs, segmented feet and a carried rifle with hollow barrels. It does not reuse the player body or the rejected recolored operator enemy batch. The editable Blender file, preserved source reference, build script and real mesh renders are in `factory/ranged`.

Remaining differences include simpler head/shoulder construction, simplified rifle silhouette and armor overlaps, fewer cables and exposed mechanisms, and preliminary procedural paint rather than authored damage/texture maps. The supplied reference is perspective and only shows one side, so the back and exact dimensions are inferred. No numeric fidelity signoff, rig/animation, runtime export, or Unity acceptance is claimed.

Continue refining this benchmark against the source before copying its construction methods. The other roles require different silhouettes: three-saw fast melee; four-legged mortar AOE; broad heavy gunner with separate shield geometry/effect. The six biome variants remain planned work, with their own approved references. No paid/cloud reconstruction or restricted Hunyuan output is used in v04.
