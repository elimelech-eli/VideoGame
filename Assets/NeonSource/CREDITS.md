# Mixed Neon source kit

## Modular Slums
AlexFerrart3D (formerly lexferreira89), https://sketchfab.com/3d-models/modular-slums-e2b6f532e1fe4f7280890971d78183f4 . CC-BY 4.0, https://creativecommons.org/licenses/by/4.0/ . Source archive SHA256 de7e578a6abd2e637b6763b74ae1abda568b951e0575f4390ebe960ef00038fa.
Conventional FBX conversion, source UVs and diffuse maps retained. Runtime kit uses one 1.25 conversion from native 2m units to 2.5m architectural cells, consistently for intact huts and derived facade strips. Source facade crops are intentionally finished with solid top/back/end caps. No texture rebake or generated replacement meshes.

## Sci-Fi Buildings
ChuckCG / Carlos Cardona, https://chuckcg.gumroad.com/l/kwkhj . Included exact License.pdf states: “Feel free to use these assets in your commercial or personal projects. Please don’t sell only the assets in a pack. Thank you.”
Only selected project-used FBX and material derivatives are included; original buildings.blend is excluded. Buildings remain whole and native-sized in reserved volumes outside all rooms/corridors. Source block 2 contributes capped corporate facade strips; the miniature-city block is never placed as room furniture. Selected source maps resampled to max2048, metallic/roughness packed explicitly for Unity Standard; no rebake. Source hashes in Chuck/provenance.json. These files form part of this game project, not a standalone asset-pack product.

## Original graphics
Fictional signs and graffiti were conventionally rasterized for this project. No third-party brands or generative imagery. StreetGraphics/RIGHTS.md records original work and rasterized Arial text; no font files are distributed.
